## What I do

- Android apps in React Native and Expo, and native Android in Kotlin with Jetpack Compose
- Web apps and sites in Next.js, React and Tailwind CSS, deployed on Vercel
- Backends on Supabase or Firebase: auth, data, storage, row-level security
- Play Store releases end to end: signing, target API levels, Data Safety, review fixes
